# Agent Workflow Rules

These instructions apply to any AI coding agent working in this repository.

## Required Git Workflow

1. Do not implement feature/fix changes directly on `master`.
2. Start each task from an updated `master`.
3. Create a new branch per task before making file edits.
4. Keep commits scoped and use clear commit messages.
5. Push the branch to `origin`.
6. Open a pull request to `master` with:
   - what changed
   - why it changed
   - how it was validated

If a task begins while on `master`, immediately create and switch to a new branch before continuing.
